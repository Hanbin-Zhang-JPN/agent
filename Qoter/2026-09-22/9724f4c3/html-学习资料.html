HTML 语法详细学习资料

从零开始系统学习 HTML5 —— 含语法讲解、代码示例与实时效果展示

1. HTML 是什么

HTML（HyperText Markup Language，超文本标记语言）是构建网页的基础语言。它不是编程语言,而是一种标记语言:用一系列“标签”来描述网页内容的结构和含义。

  • HTML 负责网页的结构(内容是什么)
  • CSS 负责网页的样式(长什么样)
  • JavaScript 负责网页的行为(能做什么)
如何运行? 把代码保存为 .html 文件,然后用浏览器打开即可。本资料本身就是一个 HTML 文件。

2. 文档基本结构

一个标准的 HTML 文档由以下几部分组成:

<!DOCTYPE html>              <!-- 声明文档类型为 HTML5 -->
<html lang="zh-CN">          <!-- 根元素,lang 指定语言 -->
  <head>                     <!-- 头部:元信息,不直接显示 -->
    <meta charset="UTF-8">   <!-- 字符编码,防止乱码 -->
    <title>网页标题</title>   <!-- 浏览器标签页显示的标题 -->
  </head>
  <body>                     <!-- 主体:页面可见内容 -->
    <h1>你好,世界!</h1>
  </body>
</html>
部分作用
<!DOCTYPE html>告诉浏览器这是 HTML5 文档,必须放在第一行
<html>整个文档的根元素,包裹所有内容
<head>存放元信息:编码、标题、样式、脚本引用等
<body>存放页面上真正显示给用户看的内容

3. 元素、标签与属性

元素与标签

大多数元素由开始标签、内容和结束标签组成:

<p>这是一段文字</p>
 ↑开始标签   内容   ↑结束标签

部分元素没有内容,称为空元素(自闭合),例如换行 <br>、水平线 <hr>、图片 <img>。

属性

属性写在开始标签内,用来提供额外信息,格式为 属性名="属性值":

<a href="https://example.com" target="_blank">链接</a>
     ↑属性名   ↑属性值            ↑另一个属性
通用属性说明
id元素的唯一标识,整个页面不可重复
class元素的类名,用于 CSS 选择,可重复、可多个
style内联样式
title鼠标悬停时的提示文字

4. 文本相关标签

标题 h1 ~ h6

<h1>一级标题</h1>
<h2>二级标题</h2>
<h6>六级标题</h6>
注意 一个页面通常只用一个 <h1>,标题要按层级顺序使用,不要为了字体大小随意跳级。

段落与文本格式

<p>这是段落</p>
<strong>重要(加粗)</strong>
<em>强调(斜体)</em>
<mark>高亮</mark>
<br> <!-- 换行 -->
<hr> <!-- 分隔线 -->

6. 链接与图片

超链接 a

<a href="https://example.com">外部链接</a>
<a href="#intro">页面内锚点</a>
<a href="mailto:me@qq.com">发邮件</a>
<a href="page.html" target="_blank">新窗口打开</a>

图片 img

<img src="photo.jpg" alt="图片描述" width="200">
alt 很重要 alt 是图片加载失败或屏幕阅读器读取时的替代文字,有利于无障碍访问和 SEO。

7. 表格

<table>
  <thead>
    <tr><th>姓名</th><th>年龄</th></tr>
  </thead>
  <tbody>
    <tr><td>小明</td><td>18</td></tr>
  </tbody>
</table>
实时效果
姓名年龄城市
小明18北京
小红20上海

常用标签:table 表格、tr 行、th 表头单元格、td 普通单元格。合并单元格用 colspan(跨列)、rowspan(跨行)。

9. 语义化布局标签

HTML5 提供了语义化标签,让代码结构更清晰,也利于 SEO 和无障碍访问:

<header>页眉/顶部导航</header>
<nav>导航链接</nav>
<main>主要内容</main>
<article>独立文章</article>
<section>章节区块</section>
<aside>侧边栏</aside>
<footer>页脚</footer>
div vs 语义标签 <div> 和 <span> 是无语义的通用容器。能用语义标签时优先用语义标签,实在没有合适的再用 div。

10. 多媒体与嵌入

<audio src="music.mp3" controls></audio>

<video src="movie.mp4" controls width="400"></video>

<iframe src="https://example.com" width="100%" height="300"></iframe>

controls 属性会显示播放控件。iframe 用于在页面中嵌入另一个网页。

11. 常用元信息与 SEO

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="网页描述,搜索结果会显示">
<meta name="keywords" content="关键词1,关键词2">
<link rel="stylesheet" href="style.css">
<link rel="icon" href="favicon.ico">

其中 viewport 那行对移动端适配至关重要,几乎每个页面都要加。

12. 特殊字符实体

某些字符在 HTML 中有特殊含义(如 < >),需要用实体代替:

字符实体写法说明
<&lt;小于号
>&gt;大于号
&&amp;与符号
空格&nbsp;不换行空格
"&quot;双引号
©&copy;版权符号

13. 完整实战示例

下面是一个包含常见结构的完整页面,你可以复制到新文件中运行:

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>我的第一个网页</title>
</head>
<body>
  <header>
    <h1>我的博客</h1>
    <nav>
      <a href="#">首页</a> |
      <a href="#">关于</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>第一篇文章</h2>
      <p>这是文章正文,包含<strong>重点</strong>内容。</p>
      <img src="cover.jpg" alt="封面图">
      <ul>
        <li>要点一</li>
        <li>要点二</li>
      </ul>
    </article>
  </main>

  <footer>
    <p>&copy; 2026 我的博客</p>
  </footer>
</body>
</html>

14. 良好实践建议

  • 始终写 <!DOCTYPE html> 和 <meta charset="UTF-8">
  • 标签名和属性名统一使用小写
  • 属性值用双引号包裹
  • 正确嵌套标签,不要交叉:<p><strong>对</strong></p>
  • 图片一定加 alt,表单控件配 <label>
  • 优先用语义化标签,让机器和人都读得懂
  • 保持代码缩进整齐,便于阅读维护
  • 结构(HTML)、样式(CSS)、行为(JS)分离
下一步学什么? 掌握 HTML 后,建议学习 CSS(美化页面)和 JavaScript(交互功能),三者结合就能做出真正的网站。
