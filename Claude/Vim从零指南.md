## 1. JIS 键盘与 Vim 的关键差异

Vim 的命令高度依赖符号键（`:` `/` `\` `^` `~` `|` 等），而 JIS 布局在这些键的位置和是否需要 Shift 上，和大多数英文教程默认的 US 键盘不同。先弄清这几点，能省掉后面大量"为什么敲不出这个符号"的困惑。

| 符号 | US 键盘 | JIS 键盘 | 对 Vim 的影响 |
| --- | --- | --- | --- |
| `:` | Shift + ; | 独立按键，**不需要 Shift** | 命令行模式的 `:` 在 JIS 上其实更顺手 |
| `\`（反斜杠） | 独立按键 | 物理键印的是 **¥（日元符号）**，实际输入的是反斜杠 | Vim 默认 leader 键常是 `\`，在 JIS 上要去按印着 ¥ 的那个键，容易找错 |
| `^` `~` | 在 = 键旁 | 在数字 0 右侧、¥ 键左侧的独立键上 | 正则、行首匹配 `^` 用得多，位置需要肌肉记忆重建 |
| `[` `]` `{` `}` | P 键右侧两个键 | 大体同位，但和 Shift 组合略有差异 | 代码块跳转 `{` `}` 影响不大，用前建议实测一次 |
| `_`（下划线） | Shift + - | 在「ろ」键（右 Shift 左侧的额外键）上，需要 Shift | Vim 中 `_` 也是移动命令（行首非空白字符），键位偏僻容易漏按 |
| Esc | 独立物理键（老款） | Touch Bar 机型上是虚拟按键，非 Touch Bar 机型有物理键但位置偏远 | Vim 中退出插入模式最高频的键，强烈建议重新映射（见下） |

**关于 Esc 的建议：**无论是不是 JIS 键盘，Vim 老手几乎都会把 Caps Lock 重新映射成 Esc，因为 Caps Lock 位置好按、日常又几乎用不到大写锁定。 路径：系统设置 → 键盘 → 键盘快捷键 → 修饰键，把 Caps Lock 改成 Esc。 如果想要"单独按是 Esc，按住再配合别的键是 Control"的进阶映射，需要 [Karabiner-Elements](https://karabiner-elements.pqrs.org/)。

## 2. 开始之前：终端与初始设置

macOS 自带 Vim，但版本较旧、功能阉割（不支持剪贴板等）。建议先装一个更完整的版本：

```
brew install vim
# 或直接用更现代的实现
brew install neovim
```

本文档所有命令对 `vim` 和 `nvim` 通用， Neovim 只是在插件生态和默认配置上更现代，操作逻辑完全一致。

## 3. 模式：Vim 的核心概念

理解 Vim 的第一步，也是唯一真正重要的一步，是接受它不是"打字机"，而是一个带状态机的编辑器。 同一个按键在不同模式下含义完全不同。

| 模式 | 进入方式 | 用途 |
| --- | --- | --- |
| Normal（普通） | 默认模式，或按 Esc | 移动光标、执行命令，不直接输入文字 |
| Insert（插入） | i / a / o 等 | 像普通文本编辑器一样打字 |
| Visual（可视） | v / V / Ctrl+v | 选中文本再操作 |
| Command-line（命令行） | : | 保存、退出、替换、执行 Ex 命令 |

新手最常见的错误就是在 Insert 模式下试图移动光标或执行命令，结果打出一堆乱码字符。 记住一条原则：**不确定自己在哪个模式，先按一次 Esc 回到 Normal 模式**。

## 4. 启动与退出

```
vim 文件名        # 打开/新建文件
vim               # 不带文件名打开
```

| 命令 | 作用 |
| --- | --- |
| `:w` | 保存 |
| `:q` | 退出（无修改时） |
| `:wq` 或 ZZ | 保存并退出 |
| `:q!` | 放弃修改并强制退出 |
| `:x` | 有修改才保存，然后退出 |

## 5. 光标移动

Vim 不鼓励用方向键（虽然也能用），核心是 h j k l，好处是手不用离开主键位。

| 按键 | 动作 |
| --- | --- |
| h / l | 左 / 右 |
| j / k | 下 / 上 |
| w | 跳到下一个单词开头 |
| b | 跳到上一个单词开头 |
| e | 跳到当前/下一个单词末尾 |
| 0 | 跳到行首（含空白） |
| `^` | 跳到行首第一个非空白字符 |
| `$` | 跳到行尾 |
| gg | 跳到文件开头 |
| G | 跳到文件末尾 |
| 数字 + G | 跳到第 N 行，如 `42G` |
| fx | 跳到本行下一个字符 x |
| tx | 跳到 x 前一个字符 |
| `{` / `}` | 按段落向上/向下跳 |
| Ctrl+d / u | 向下/向上翻半屏 |

**数字前缀通用规则：**几乎所有移动和编辑命令前都能加数字表示重复次数，例如 `5j` 向下 5 行，`3w` 向后跳 3 个单词。 这是 Vim 效率的关键之一，比连续按键快得多。

## 6. 基础编辑

### 进入插入模式

| 按键 | 作用 |
| --- | --- |
| i | 在光标前插入 |
| a | 在光标后插入 |
| I | 在行首插入 |
| A | 在行尾插入 |
| o | 在下方新起一行插入 |
| O | 在上方新起一行插入 |

### 删除、复制、粘贴

| 按键 | 作用 |
| --- | --- |
| x | 删除光标处一个字符 |
| dd | 删除（剪切）一整行 |
| dw | 删除到下一个单词开头 |
| d$ | 删除到行尾 |
| cw | 删除一个单词并进入插入模式（改词的标准做法） |
| yy | 复制一整行 |
| p | 在光标后粘贴 |
| P | 在光标前粘贴 |
| u | 撤销 |
| Ctrl+r | 重做 |
| `.` | 重复上一次修改操作 |

**动作的组合逻辑：**`d`（删除）、`c`（改）、 `y`（复制）都可以和第 5 节的移动命令组合，构成"动词 + 范围"的语法， 例如 `d}` 删到段落结尾，`c$` 改到行尾。 这是 Vim 真正的核心设计，比背单条快捷键重要得多。

## 7. 可视模式

| 按键 | 作用 |
| --- | --- |
| v | 逐字符选择 |
| V | 整行选择 |
| Ctrl+v | 块选择（按列选中，改多行同一位置很有用） |

选中后可以直接接 `d`（删除）、`y`（复制）、 `>` / `<`（缩进）等操作。

## 8. 查找与替换

| 命令 | 作用 |
| --- | --- |
| `/pattern` | 向下查找 |
| `?pattern` | 向上查找 |
| n / N | 下一个 / 上一个匹配 |
| `:%s/old/new/g` | 全文替换所有 old 为 new |
| `:%s/old/new/gc` | 同上，逐个确认 |
| `:5,10s/old/new/g` | 只替换第 5\~10 行 |

在 JIS 键盘上输入 `:` 不需要 Shift，比 US 键盘更顺手，但正则里常用的 `^` `$` 位置不同，写复杂正则时建议放慢速度确认符号。

## 9. 寄存器与系统剪贴板

Vim 的复制粘贴默认走"无名寄存器"，和 macOS 系统剪贴板是两回事。要和其他 App 互相粘贴，需要显式指定寄存器：

```
"+y   " 复制到系统剪贴板（先选中文本，再执行）
"+p   " 从系统剪贴板粘贴
```

**前提：**系统自带的 Vim 不一定支持 `+clipboard`。 运行 `vim --version | grep clipboard` 查看，如果显示 `-clipboard`（带减号）说明不支持，需要用 `brew install vim` 装带剪贴板支持的版本。

## 11. 宏

把一串操作录制下来重复执行，是 Vim 批量编辑的核心手段之一。

```
qa      开始把接下来的操作录制到寄存器 a
...     执行你想重复的操作
q       停止录制
@a      执行一次寄存器 a 里的宏
10@a    连续执行 10 次
@@      重复上一次执行的宏
```

## 12. 配置文件 .vimrc

配置文件位于 `~/.vimrc`（Neovim 是 `~/.config/nvim/init.vim`）。一个可用的起步版本：

```
set number          " 显示行号
set relativenumber " 相对行号，方便配合数字前缀移动
set expandtab       " Tab 转空格
set tabstop=2
set shiftwidth=2
set ignorecase      " 搜索忽略大小写
set smartcase       " 但输入大写时区分大小写
set incsearch       " 输入时实时高亮搜索结果
set clipboard=unnamed " 让 y/p 默认使用系统剪贴板
```

前面提到 JIS 键盘上默认 leader 键 `\` 藏在印着 ¥ 的键上，很多人会在 .vimrc 里把它改成更好按的键，例如：

```
let mapleader = " "   " 把 leader 换成空格键
```

## 13. 中文/日文输入法的坑

这一节和 JIS 键盘本身无关，但对中文/日文用户几乎必然遇到：在插入模式下用系统输入法打完字后， 直接按 Esc 切回 Normal 模式，输入法的候选框有时不会立刻退出，导致下一次进入插入模式时 还带着输入法状态，出现"明明按了字母键却在打拼音"的情况。

- 养成习惯：打完一段文字后先按一次 Esc 确认候选框已消失，再操作。
- 部分场景可以用 `im-select` 之类的工具，让 Vim 退出插入模式时自动切回英文输入法。
- Neovim 用户也可以配置 `autocmd` 在离开插入模式时调用系统命令切换输入法，但配置成本较高，先跑通基础操作再考虑。

## 14. 学习路径与资源

1. 终端里运行 `vimtutor`（自带，中文版可用 `vimtutor zh`），大约 30 分钟，覆盖本文档前 8 节的全部内容，动手做一遍比读文档有效。
2. 连续两周，日常编辑文本（哪怕不写代码）都强制用 Vim，肌肉记忆是唯一有效的学习方式。
3. 熟练基础操作后再考虑插件（如文件树 NERDTree、模糊搜索 fzf、LSP 补全），过早引入插件会掩盖对原生操作的掌握。
4. 如果决定长期使用，评估迁移到 Neovim：配置生态更活跃，语法基本兼容。
