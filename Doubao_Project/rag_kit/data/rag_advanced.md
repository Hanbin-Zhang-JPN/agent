# RAGの高度な活用

【評価の重要性】
RAG システムを本番運用する際は、品質を定量的に評価することが重要です。
代表的な指標として、関連文書を正しく検索できたかを測る「再現率」や「適合率」があります。
また、生成した回答の正しさを確認するために、正解付きのテストデータセットを作ることも一般的です。
評価を繰り返すことで、チャンクサイズや検索方式の改善につなげられます。

【類似度の改善】
文書の類似度計算は、単純な文字列の一致だけでは不十分なことがあります。
同義語や表記ゆれを扱うには、複数の文字をまとめた「n-gram」を使うと精度が上がります。
日本語では1文字単位より2文字単位の bi-gram が実用的な精度を出す傾向があります。
また、出現頻度の高い語と希少な語をバランスよく扱うため、TF-IDF による重み付けが効果的です。

【メモリと速度の工夫】
大規模な文書を扱う際は、メモリと速度のバランスが課題になります。
ベクトルを固定次元へ圧縮する「特徴ハッシュ」を使うと、記憶量を抑えながら検索できます。
また、検索候補を絞り込んでから類似度を計算することで、処理を高速化できます。
いずれも内部の計算が分かっていれば、用途に応じて調整しやすくなります。

【運用上の注意】
RAG を運用する際は、文書の更新と品質管理が欠かせません。
古くなった情報は削除・更新し、常に最新の状態を保つことが大切です。
また、回答の根拠を必ず参照元と紐づけて表示することで、利用者が内容を検証できます。
これらの運用をしっかり行うことで、RAG は実用的な情報システムとして機能します。
