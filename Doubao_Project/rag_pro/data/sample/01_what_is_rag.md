# 什么是 RAG（检索增强生成）

RAG 是"检索增强生成"（Retrieval-Augmented Generation）的英文缩写。

它的核心思想是：大语言模型在回答问题时，先从一个外部知识库中
检索出与问题相关的资料，再把这些资料作为参考，让模型基于资料
生成答案。这样既发挥了模型的语言能力，又让回答有据可依。

RAG 相比纯大模型问答有三个明显优势。第一，答案可以追溯来源，
每一句话都能对应到具体的文档段落，方便用户核对。第二，知识可以
随时更新，不需要重新训练模型，只要往知识库里添加新文档即可。
第三，回答更加准确，大幅降低了模型"一本正经地胡说八道"的幻觉问题。

典型的 RAG 流程分为五个步骤：文档切块、向量化与建索引、检索、
重排、生成。切块是把长文档切成小片段；向量化是把文本变成可比较
的数值向量；检索是从知识库中召回最相关的片段；重排是对召回结果
做精细排序；生成是让模型基于选中的片段写出最终答案。
