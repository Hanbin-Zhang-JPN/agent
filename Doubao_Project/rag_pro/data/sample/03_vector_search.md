# 向量检索与余弦相似度

向量检索是 RAG 的另一种核心检索方式，它把文本表示成数值向量，
通过比较向量之间的距离来判断文本的语义相似程度。

把文本变成向量的过程叫做"向量化"或"嵌入"（Embedding）。向量化
的方式有很多种，最简单的是词袋模型加 TF-IDF 权重：统计文本中每个
词的出现频率，乘以词的稀有程度权重，得到一个高维稀疏向量。更高级
的方式是用神经网络模型生成稠密向量，这类模型经过训练，能把"苹果"
和"水果"这类语义相近但字面不同的词映射到接近的位置，因此能理解
同义词和上下文含义。

比较两个向量是否相似，最常用的指标是余弦相似度。它计算两个向量
夹角的余弦值，公式为：两个向量的点积除以各自模长的乘积。余弦值
越接近 1，表示两个向量的方向越一致、语义越接近；越接近 0，表示
越不相关。余弦相似度只关心方向、不关心长度，因此对文本长度不敏感，
非常适合文本比较。

在 RAG 中，检索时先把查询也向量化，然后逐一计算查询向量与知识库
中每个块向量的余弦相似度，取最相似的一批作为候选。这一步通常与
BM25 关键词检索同时进行，再把两路结果融合，达到更好的召回效果。
