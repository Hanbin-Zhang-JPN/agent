# BM25 关键词检索算法

BM25 是信息检索领域最经典的排序算法之一，全称是 Okapi BM25。
它属于"词法检索"，核心是依据查询词与文档中关键词的匹配程度打分。

BM25 的分数主要由三个部分构成。第一是词频 TF，即关键词在文档中
出现的次数，出现越多分数越高，但会设置饱和上限，避免重复堆词。
第二是逆文档频率 IDF，即一个词在多少文档中出现过，出现越少说明
越稀有、区分度越高，权重越大。第三是文档长度归一化，防止长文档
因为词多而天然占优。

BM25 有两个经典超参数：k1 控制词频的饱和程度，默认 1.5；b 控制
长度归一化的强度，默认 0.75。这两个值在大多数场景下表现稳定，
一般无需调整。

在 RAG 中，BM25 通常与向量检索结合使用，构成"混合检索"。BM25
擅长精确匹配专业术语和稀有词，向量检索擅长理解同义表达和语义，
两者互补。融合时常用 RRF（Reciprocal Rank Fusion，倒数排名融合）
算法：对每个结果，根据它在两份榜单中的名次分别累加 1/(名次+60)，
最终按融合分排序。RRF 只依赖名次不依赖原始分数，实现简单且稳定。
