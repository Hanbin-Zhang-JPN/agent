# 重排、上下文组装与减少幻觉

检索召回一批候选片段后，还需要经过"重排"和"上下文组装"，最终
才能交给大模型生成答案。

重排（Rerank）是对粗召回结果做第二次精细排序。粗召回阶段通常
返回几十条结果，但真正相关的可能只有几条，且顺序未必正确。重排
会综合多种信号重新打分：BM25 关键词命中分数、向量语义相似度、
片段在文档中的位置、查询词在片段中的直接命中率等。加权求和后，
把真正相关的片段排到最前面。有些实现还会引入 MMR（最大边际相关）
算法，在保证相关性的同时避免选中的片段内容过于重复，让答案覆盖
更多不同的信息点。

上下文组装（Context Assembly）负责把选中的片段整理成适合送进
模型的格式。它要做几件事：去掉重复片段、按 token 预算裁剪长度、
给每个片段编号并标注来源。最终生成一份带引用的材料，供模型参考。

减少幻觉是 RAG 的关键目标之一。在提示词中明确要求模型"只依据
参考材料回答、引用编号、找不到就明说不知道"，能显著降低模型
编造内容的概率。引用溯源机制则让每一句话都能查到出处，方便用户
核对答案的真实性。
