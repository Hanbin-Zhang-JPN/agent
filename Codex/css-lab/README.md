# CSS Lab

一个可以直接动手的中文 CSS 学习项目。8 节课程从基础样式走到响应式和动画，每节都有讲解、可编辑代码、实时预览和参考答案。

## 开始使用

直接用浏览器打开 `index.html` 即可。也可以在本目录运行静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 学习方式

1. 从左侧选择课程，阅读概念和本节任务。
2. 在 HTML / CSS 编辑器中修改代码，右侧预览会实时更新。
3. 卡住时先看提示，再查看参考答案。
4. 完成后手动标记本节完成。进度和代码保存在当前浏览器的 `localStorage` 中。

所有代码都在本地运行，不需要安装依赖，也不需要注册账号。可按 `⌘/Ctrl + Enter` 立即刷新预览。参考答案是学习示例，不是唯一正确写法。

## 项目结构

- `index.html`：页面结构
- `styles.css`：学习平台的界面样式
- `lessons.js`：课程内容、起始代码与参考答案
- `app.js`：课程切换、编辑器、预览和进度保存
